## 元模型≠由模型生成的 XML Schema

[R24-11 发布概览第 3 章](https://www.autosar.org/fileadmin/standards/R24-11/FO/AUTOSAR_FO_TR_ReleaseOverview.pdf)及[R23-11 发布概览第 3 章](https://www.autosar.org/fileadmin/standards/R23-11/FO/AUTOSAR_FO_TR_ReleaseOverview.pdf)分别列“Meta Model”与“Meta Model-generated XML Schema”为**两个不同交付物**。实际下载交叉验证：[R24 XMLSchema ZIP](https://www.autosar.org/fileadmin/standards/R24-11/FO/AUTOSAR_FO_MMOD_XMLSchema.zip)有 `AUTOSAR_00053.xsd`、`xml.xsd`、`autosar.soc`、两个说明文本，实算 SHA-256 `9db3ab1d2ec4db7cc8ff09f1259ff93a7a5945a9500d4cd3ea4a7090f2a25766`；[R23 XMLSchema ZIP](https://www.autosar.org/fileadmin/standards/R23-11/FO/AUTOSAR_FO_MMOD_XMLSchema.zip)相应为 `AUTOSAR_00052.xsd` 等，实算 `75056bce077c66a657ace5fd00542c613be31a47df9ffba4c605fc80d3eeb7f3`，分别匹配[R24](https://www.autosar.org/fileadmin/standards/R24-11/FO/AUTOSAR_FO_TR_SpecificationHashes.sha256)/[R23](https://www.autosar.org/fileadmin/standards/R23-11/FO/AUTOSAR_FO_TR_SpecificationHashes.sha256)清单。这两份 Schema ZIP **没有** `.qea` / `.eap` 模型。[R24 概览版本映射](https://www.autosar.org/fileadmin/standards/R24-11/FO/AUTOSAR_FO_TR_ReleaseOverview.pdf)给出 R23-11=`AUTOSAR_00052`、R24-11=`AUTOSAR_00053`。

`MOD_SpecificationsARXML.zip` 在 R24 官网标题为“Specifications in ARXML format”，且实际含多份规范的 ARXML 与配套素材；它不是 MetaModel，也不是单独的 XML Schema。`TR_ChangeDocumentation.zip` 在[R25-11 FO 官方哈希清单](https://www.autosar.org/fileadmin/standards/R25-11/FO/AUTOSAR_FO_TR_SpecificationHashes.sha256)归入 `ReleaseDocumentation/`，从名称可知意图是变更文档归档，但未获得 ZIP 正文，不应推断其具体记录格式、覆盖范围或文件成员。

**不能跨版补缺：** [R25-11 FO 哈希清单](https://www.autosar.org/fileadmin/standards/R25-11/FO/AUTOSAR_FO_TR_SpecificationHashes.sha256)明确分别要求 `MOD_SpecificationsARXML.zip`=`ec01a806dc85b3d69f9b8dadc810f7a8181df17fe6d59e2feb230941c5d4479d`、`TR_ChangeDocumentation.zip`=`242757882680b5125d19c19357410ff2fda64327e3206a5fcd5bded886ca4465`、`MMOD_MetaModel.zip`=`75aefbf9d5eac9623a2619f183db20f0815db8e3bb824a5c6cb7a377675e1ea9`。上述已验证旧版的实际哈希均不等于 R25 对应目标；即使可读旧版 `.qea`/`.eap`，也只能用作历史对照，**不可计入 R25-11 已获取或改名后代用**。

核验方法：官方搜索的 **FO+发行版** 过滤结果、官方 SHA-256 清单和发布概览；对已列出的 ZIP 实际 HTTP GET、在内存中计算完整正文 SHA-256 并读取 ZIP 中央目录/说明文本；对未列出的候选链接仅用 HEAD 验证具体 404。哈希清单中的 `ReleaseDocumentation/`、`MethodologyAndTemplates/` 是发行包内部分类路径，不应未经官网索引就当成网站 URL。无 ZIP 写入 `docs/`。
