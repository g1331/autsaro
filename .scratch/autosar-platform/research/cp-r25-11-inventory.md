# AUTOSAR Classic Platform R25-11 官方发布清单

## 范围与来源

- 官方 [Classic Platform 页面](https://www.autosar.org/standards/classic-platform)将当前版本标为 R25-11；[CP Release Overview](https://www.autosar.org/fileadmin/standards/R25-11/CP/AUTOSAR_CP_TR_ReleaseOverview.pdf)给出版本映射：发布号 `R25-11`、内部号 `R4.11.0`、模式版本 `AUTOSAR_00054`，属 minor release。
- [官方文档搜索：R25-11 + CP](https://www.autosar.org/search?tx_solr%5Bfilter%5D%5B0%5D=category%3AR25-11&tx_solr%5Bfilter%5D%5B1%5D=platform%3ACP)显示 **218 Documents found**。按 Web Doc Type 分面逐页枚举，计数 `ASWS 1, EXP 22, MOD 4, RS 45, SWS 127, TPS 7, TR 12`，合计 218。每个下表 URL 均从对应的官方搜索结果链接读取，未由文件名推算；表内 `来源页` 是这一直接链接所在页面。
- 官方 [CP SpecificationHashes.sha256](https://www.autosar.org/fileadmin/standards/R25-11/CP/AUTOSAR_CP_TR_SpecificationHashes.sha256)列出 **219 个已哈希文件**（212 PDF、7 ZIP），但不包含自身。与搜索交叉核验：共同 217 个；搜索独有 `AUTOSAR_CP_TR_SpecificationHashes.sha256`；哈希清单独有下述 2 个 ZIP。因此**命名范围 220 个：212 PDF、7 ZIP、1 SHA256**；仅 **218 个**获得官方搜索结果中的可下载直链。哈希列只表示发布清单宣称的校验值；未下载二进制、未逐文件校验。
- `发布包内路径`取自哈希清单，描述包内分类，不可当作官网 URL 路径。官网直链通常是扁平 `.../R25-11/CP/<文件名>`，但未收录的 2 个 ZIP 不能据此推断；这两项留空。
