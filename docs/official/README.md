# AUTOSAR 官方资料（本地参考）

按发布版本隔离，避免将不同版本的规范和 XML Schema 混用：

- [R24-11](R24-11/README.md)：首个产品基线，CP/FO 官方校验清单 301/301 项已取得并验证。
- [R25-11](R25-11/README.md)：未来升级的参考资料；官方发布文件仍有五项未能验证。

需要长期引用的规范原件保存在仓库外的持久目录，例如当前维护环境采用的 `../autsaro-official-specs`。按标准和版次隔离，保留原件字节、来源、官方哈希清单及收到字节的摘要；收到字节的摘要本身不等于出版方摘要匹配。临时目录可保存可重建的提取文本、页面图片和实验副本，不作为唯一原件位置。普通开发不需要先准备整套规范或取得私有资料库。

官网收集入口是 `python scripts/collect_official_specs.py R24-11`，输出到 `docs/official/R24-11/` 并按官方清单校验。有私有资料库访问权限的维护者，也可在该库目录运行 `specs.py restore R24-11 [DIR]` 或 `specs.py verify R24-11 [DIR]` 恢复或核验副本。需要官方对照的检查通过已有路径参数或[档案环境变量](../standards/README.md#2-官方资料与本地位置)引用所需文件；示例持久目录不是工具自动发现的默认值。

官方 PDF、ZIP、MISRA／ISO 原件和提取全文均不提交到产品仓库或随产品再分发；仓库只保留资料索引。首个产品实现的规范基线为 CP/FO R24-11，R25-11 留作后续升级。
