# AUTOSAR 官方资料（本地参考）

按发布版本隔离，避免将不同版本的规范和 XML Schema 混用：

- [R24-11](R24-11/README.md)：首个产品基线，CP/FO 官方校验清单 301/301 项已取得并验证。
- [R25-11](R25-11/README.md)：未来升级的参考资料；官方发布文件仍有五项未能验证。

规范原件统一保存在产品仓库外的持久资料目录，本机默认位置为项目相邻的 `../autsaro-official-specs`，按标准和版次隔离：AUTOSAR 使用 `R24-11/CP/`、`R24-11/FO/` 的官方分类，MISRA 使用 `MISRA/C-2012/`，ISO 按编号与年份保存。其他位置通过工具路径参数和已有环境变量指定，不在产品或 CI 硬编码本机绝对路径，不设置宿主全局环境。`/tmp` 只存可重建的提取文本、页面图片和实验副本，不作为唯一原件位置。

与原件一并保存官方哈希清单、收到字节的摘要、版次与来源记录；原件字节保持不变。项目提供文件的收到字节摘要不等于出版方摘要匹配。已有私有资料库的 `specs.py restore R24-11 [DIR]` 恢复官方文件，`specs.py verify R24-11 [DIR]` 校验已有副本；从该资料库目录运行，默认使用其对应版次目录。沿用这些工具，不另建下载入口。开发对照档案的四个路径变量见[标准基线](../standards/README.md#2-官方资料与本地位置)，仅对任务命令设置；`core/resources/official.json` 的跨平台相对默认路径保持不变。

官方 PDF、ZIP、MISRA／ISO 原件和提取全文均不提交到产品仓库或随产品再分发；仓库只保留资料索引。首个产品实现的规范基线为 CP/FO R24-11，R25-11 留作后续升级。
