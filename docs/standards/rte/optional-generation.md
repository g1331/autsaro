# RTE：测量、标定、跟踪与其他生成选项

范围与核算见 [RTE](README.md)，已选主线见[接口与生成阶段](contracts.md)。主线明确选择 measurement=false、calibration=NONE、bypass=NONE、VFB trace=false、range check=false、DevErrorDetect=false，对应非主线值均在实际参数处拒绝。以下条目保留这些具体启用条件；关闭时仍必需的 MC-Support NONE、类型和配置头已在当前主线实现。工具必须提供某种启用模式的无条件能力要求保留在 #212，不写成已满足。

完整支持的进入条件和退出证据由 [#212](https://github.com/g1331/autsaro/issues/212) 保留；未排期，不构成当前新增支持承诺。
