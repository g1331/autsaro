# BSW General：Can

本篇属于 [BSW General](README.md)，标记与核算方法见[标准与规范基线 §5](../README.md#5-条款处置与核算)。

`SWS_BSWGeneral` 的全部 150 条对 Can 单独处置，标记带 `[Can]`。由测试验证的条目见 `core/tests/fixtures/bsw-contracts/can_contract.c`（`SWS_BSW_00037` 未初始化时主函数直接返回、`00071` Init 结束时控制器为 STOPPED、`00186` 输入指针为 const、`00219`／`00222` 以 uint8 向 Det 报告运行时错误）与 `can_callback_lifetime.c`（`00134` 独占区只保护模块数据）。Can 属于 MCAL，主机实现对应受控主机目标；只能在真实控制器上成立的义务由 #170 交给 R10。“配置”类的依据与 [Can](../can.md) 篇相同，对应参数在生成前被拒绝。
