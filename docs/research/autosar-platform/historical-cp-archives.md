**内容与用途。** R24-11 MOD 包的官方 `_readme.txt`（见[原 ZIP](https://www.autosar.org/fileadmin/standards/R24-11/CP/AUTOSAR_CP_MOD_SpecificationsARXML.zip)）自述 Document ID **1127**、Classic Platform **R24-11**、published、日期 **2024-11-27**，内容为“**AUTOSAR Classic Platform in machine-readable ARXML format**”，使用文档序列化器约定 v1.0，另带 XML 命名空间的 `xml.xsd`。实测按 Range 读取中央目录得 **4,964 项**，包括 `_readme.txt`、`_disclaimer.txt`、`CP_ASWS_TransformerGeneral_658/AUTOSAR_CP_ASWS_TransformerGeneral.arxml`、其 `figures/` 附件和 `xml.xsd`；这表明它是机器可读的规范表示及附件集合，**不是**只含单个 ECU 配置的 ZIP。`_disclaimer.txt` 限定材料用途／知识产权，能够取得不等于可以任意再分发。以上是对 ZIP 原件的范围读取，不是仅凭文件名猜测。

关于 `ChangeDocumentation`：现有 [CP R24-11 Release Overview §2.3、§3](https://www.autosar.org/fileadmin/standards/R24-11/CP/AUTOSAR_CP_TR_ReleaseOverview.pdf#page=18) 与 [CP R23-11 Release Overview §3](https://www.autosar.org/fileadmin/standards/R23-11/CP/AUTOSAR_CP_TR_ReleaseOverview.pdf#page=19) 分别说明发布文档／列出发布规范；两版报告的逐规格变更摘要确有“for details please refer to the ChangeDocumentation”字样（[R24-11 页 36、39 等](https://www.autosar.org/fileadmin/standards/R24-11/CP/AUTOSAR_CP_TR_ReleaseOverview.pdf#page=36)、[R23-11 页 38、41 等](https://www.autosar.org/fileadmin/standards/R23-11/CP/AUTOSAR_CP_TR_ReleaseOverview.pdf#page=38)），指向详细变更记录这一**用途**，但此引用不构成这些版本的同名独立 ZIP 已发布／可下载的证据；尤其不应由 R25-11 哈希清单中的名字反推 R24-11／R23-11 路径。要追溯当时变化，可先阅读各自 Release Overview 的发布变化章节与具体规范修订记录，不能宣称找到了上述两个 TR ZIP。

**基线界限。** [R24-11 CP Release Overview §1.3.5](https://www.autosar.org/fileadmin/standards/R24-11/CP/AUTOSAR_CP_TR_ReleaseOverview.pdf#page=9) 明确其 CP 依赖 **FO R24-11**；R23-11 [Overview §1.3.6](https://www.autosar.org/fileadmin/standards/R23-11/CP/AUTOSAR_CP_TR_ReleaseOverview.pdf#page=9) 明确依赖 **FO R23-11**。MOD ZIP 内 `_readme.txt` 亦自报 R24-11。故它只可作历史对照／另立 R24-11 基线输入，**不是 R25-11 的五个缺失工件之一的合格替代**；不能复制进 R25-11 目录、冒用 R25-11 哈希或混合不同版本 CP／FO 模型。公开站点的 `fileadmin/standards/<release>/CP/` 直链与哈希清单内 `ReleaseDocumentation/` 包内相对路径不是同一目录结构。

核查方式：通过 HTTPS 从 AUTOSAR 官方站点读取发布 PDF、SHA-256 文本、搜索结果 HTML；对四个候选同版直链执行 HEAD 与带 `Range: bytes=0-15` 的 GET；对唯一成功 ZIP 再仅以字节范围读取 ZIP 目录和两个文本成员，未将任何二进制放入 docs。当前环境对 AUTOSAR 站点证书链的默认验证失败，因此上述 HTTP 实测显式绕过了**本机证书验证**；状态、长度和 ZIP 可解析性是实测，服务端身份未由本机 CA 链独立验证。未对整包计算哈希，不把清单所列预期值写成实测摘要。
