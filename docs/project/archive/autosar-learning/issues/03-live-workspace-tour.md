## Question

用可点击的低保真原型比较从独立学习页启动、进入真实配置/诊断/生成/虚拟运行页高亮控件、执行动作并返回学习页的导览方式。高亮框应解释“这是什么、点了会发生什么、下一步为何在这里”，但不建立第二编辑器；当项目未保存、控件不可用、对象消失、窗口缩放、键盘/读屏操作、用户跳过或中途退出时，怎样暂停、恢复或安全降级？原型应让学习者亲自反应并锁定交互规则，不作为正式功能交付。
