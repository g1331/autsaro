# 长期候选目录

本篇属于[路线图](README.md)：近期顺序、待决问题与仍然有效的需求约束见路线图正文。


R-ID 是路线标识，不是 Issue 或 Milestone 编号；正式开工时为其建立 Milestone 并在此注明。每项目标是可用工程成果，不是一次完成同名模块族的全部配置。网络、通道、服务、路由与映射必须作为可操作对象接入统一工作区，不仅追加模块表单；各网络不借用其他网络的通过证据。
