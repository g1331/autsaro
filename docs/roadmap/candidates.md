# 长期候选目录

本篇属于[路线图](README.md)：近期顺序、待决问题与仍然有效的需求约束见路线图正文。


R-ID 是路线标识，不是 Issue 或 Milestone 编号；正式开工时为其建立 Milestone 并在此注明。每项目标是可用工程成果，不是一次完成同名模块族的全部配置。网络、通道、服务、路由与映射须接入统一工作区，各网络分别取证。[主机最低功能范围](reference-ecu.md)中已定义的 OS／RTE、LIN、存储、配置工具与可选包在 MCU 前交付，R30 发展运行／仿真／可视化；R10 可以后移，其他候选也可按价值提前，不以最小上板组合限制功能。

并行扩展轴：新增 MCU／工具链（每个目标单独固定驱动、许可、端口和行为证据）；其他规范版次与外部互操作（显式迁移，不继承 R24-11 证据）；开源发布（每次单独核定许可、依赖与支持承诺）；Adaptive Platform 单独立项，不预造共用 CP/AP 实现；学习层待多类工程场景稳定后再决定是否规划。
